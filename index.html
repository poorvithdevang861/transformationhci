Transformation Animator

Visual reasoning study

Spot the rule. Apply it.

Each puzzle shows A : B :: C : ? — figure A changes into B by a few transformations (turning, flipping, resizing, slanting, filling). Apply the same changes to C and pick the figure that comes next.
